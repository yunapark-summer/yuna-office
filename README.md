# 👑 유나 비서실

따뜻한 크림 톤의 개인 비서실 웹앱. 브라우저에서 바로 열리는 정적 사이트입니다.

## 구성

| 탭 | 내용 |
| --- | --- |
| 🗺️ 오피스 맵 | 클레이 3D 오피스 일러스트 / 기본 플랫 맵 전환, 방 핀 이동, 움직임 ON·OFF |
| 💬 회의실 | 대회의실 · 지휘실 · 라운지 3개 방, 멘션(@하비서 · @엠디 · @라미 · @아카이브 · @all)에 따라 비서가 답장 |
| 📋 작업실 | 할 일 추가 · 완료 체크 · 삭제, 필터, 진행률 |
| 📊 비서현황 | 비서 4명 상태 카드, 담당 영역, 최근 한 일 |
| ⚡ AI한도 | 루틴 · 업무량 · 집중 에너지 게이지 (직접 조절) |
| 📝 메모 | 자동 저장 메모장 |

## 저장 방식

모든 기록(대화, 할 일, 게이지 값, 메모)은 브라우저 `localStorage`에만 저장됩니다. 서버로 전송되지 않으며, 방문 기기마다 따로 보관됩니다.

## 파일

- `index.html` — 앱 전체 (HTML · CSS · JS 단일 파일)
- `assets/office-clay.jpg` — 오피스 맵 클레이 일러스트
